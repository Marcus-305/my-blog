## 为什么开始写博客？

我希望通过博客记录自己的学习过程，
把零散的知识整理成系统的笔记。

## 为什么选择 GitHub Pages？

GitHub Pages 可以直接托管静态网页，
而 Jekyll 让我们能够使用 Markdown 写文章。

不需要每次都手动设计网页布局，
只要添加一篇新的 Markdown 文件即可。

## 我的学习计划

接下来，我希望逐步完成：

1. 学习 HTML、CSS 和 JavaScript（才不）。
2. 记录 Python 编程中的知识点。
3. 分享自己完成的小项目。
4. 不断改进博客的设计与结构（靠你了GPT）。

## 总结

搭建博客只是第一步。

更重要的是坚持记录、持续学习，
并把自己的想法真正付诸实践。(其实是GPT写的)
